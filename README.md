# Portafolio Diego Pincha

Proyecto base de Astro con una página inicial en blanco.

## Desarrollo

```bash
npm install
npm run dev
```

## Stitch

La conexión MCP de Google Stitch está configurada en `.codex/config.toml` y usa la variable de entorno `STITCH_API_KEY`. Reinicia la tarea de Codex para que cargue la configuración MCP del proyecto. La clave no debe guardarse en el repositorio.
